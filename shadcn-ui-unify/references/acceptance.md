# 执行、覆盖与验收

完整迁移收尾时读取；局部迁移只取相关验收行。验收区分 **视觉达到目标**、**行为与基线等价**、**尚未验证**，不把截图好看当成全量功能通过。

## 落地顺序与漂移控制

1. 固定本次使用的主题 ID/version、图标子规范及 Lucide 锁定版本、用户覆盖项、官方源码版本/来源、字体发布物与文件哈希。用户指定了固定旧版时遵从；没有固定版本时用当前 v3。
2. 找到 token 的真实拥有者，建立“JSON 路径 → 项目变量/variant → 组件消费者”映射。以项目已有 CSS、主题 provider 和共享包导出为承载，不另造主题运行时或每页独立副本。
3. 先改共享组件和统一变量，再消除同角色的局部硬编码覆盖。第三方库主题、portal 根、CSS Modules、Tailwind utility 和内联 style 都要检查；内容渲染区不在全局搜索替换范围内。
4. 用代表页面验证后扩展到全部目标调用点。再次调用时只补缺口，不重复 init、下载字体、注入 provider、复制组件或浮动升级依赖。已存在的用户后续定制作为约束记录。

新增 token 必须有实际消费者；新增 variant 必须有明确语义，不为某一页面的偶然颜色另起名字。排版、圆角、spacing、状态色等在 shared primitives 集中；页面只负责业务布局。不同密度是明确的上下文选择，不是随意值的豁免。

## 最少覆盖矩阵

每个实际存在且本次受影响的共享组件家族至少选一个代表调用点；存在多种行为契约时分别覆盖。表中状态只检查产品原来支持的部分，不为完成表格而创建新功能。

| 维度 | 必查内容 | 证据 |
| --- | --- | --- |
| 字体与排版 | 中文/英文/数字、真实 400/500/600、正文/标题/表单/代码；字体成功加载、无字符回退或裁切 | 字体网络/渲染信息 + computed 样式 + 页面 |
| 基础视觉 | 语义色、圆角、边框、间距、密度、图标、阴影；变量与真实消费一致 | 抽样 computed + 各代表入口前后截图 |
| Lucide 图标 | 通用图标来源、16/20/24 档位、真实描边、语义映射、纯图标按钮名称、选中/加载/方向状态；旧库残留与品牌例外 | 导入/依赖和 SVG 盘点 + 尺寸/描边渲染检查 + 键盘与状态验证；详见 icons.md |
| favicon 与品牌 Logo | 目标品牌与内置资源一致、最终 head/资源 URL 和部署前缀正确；标签页可辨识、控制台蓝色标志等比且不裁切，品牌导航与名称保留 | 资源哈希/HTTP/MIME + 浏览器标签页及品牌入口截图；检查标准/紧凑、窄屏和原有主题，详见 brand-assets.md |
| 控件状态 | default、hover、active、focus-visible、selected/checked/indeterminate、disabled、readOnly、invalid、loading（按支持情况） | 可重复动作、焦点轨迹/状态画面 |
| 完整流程 | 输入/提交/取消/重开、导航前进后退、表格排序筛选分页、持久化与权限 | 与基线一致的结果；必要时请求次数/载荷 |
| 浮层 | 嵌套菜单/弹窗、视口边缘、Escape/外部点击、初始/返回焦点、滚动锁、草稿保留 | 键盘与鼠标操作记录 |
| 异常内容 | 长中英文标签、长 ID/URL、大数字、空值、错误、多行内容、列表尾部、加载中 | 无隐藏信息、不可达操作或新增页面横向溢出 |
| 环境 | 支持的主题、窄屏/桌面、200% 缩放、reduced-motion、可用时高对比 | 对应模式截图/实测结果 |
| 代码与运行 | 相关 typecheck/lint/tests/build、控制台、hydration、字体和资源错误 | 实际命令、结果、原有失败与新增失败区分 |

代表视口默认取 **390px、768px、1440px** 宽；额外检查 320px 重排和实际受影响断点的前后 1px。它们是测试尺寸，不是让项目采用这些 CSS 断点。没有相关变化时不必对全部页面机械跑所有组合；复杂浮层、虚拟化和受影响响应式分支必须覆盖。

## 响应式、文本与可访问性

- 保持既有 media/container queries、导航折叠和移动端专用流程。缩小视口后不得丢操作；表格/代码/画布原本需要双向滚动时保留容器滚动，不给整个页面强塞 `overflow-x:hidden`。
- 尊重既有截断和完整文本访问方式。不新增 ellipsis/line-clamp 隐藏有业务含义的文本；无断点长串可在适合的普通展示文本区域换行，输入、代码和 ID 复制行为不变。
- 200% 缩放可用；以 320 CSS px 宽检查可重排内容。保持浏览器缩放设置；检查文本行高调至 1.5、段落距 2em、字距 .12em、词距 .16em 时信息不丢失。数据表、代码等固有二维内容按其合理滚动例外评估。
- 正常文字对比度目标 **≥4.5:1**；大字 **≥3:1**（至少 24 CSS px，或至少约 18.67px 且粗体；不确定字重是否满足时仍按 4.5 检查）。有效控件边界、状态图形和焦点指示在相邻背景上目标 **≥3:1**。装饰分隔线不需要冒充输入框边界。
- 测真实背景与 hover/active/selected/invalid 状态；placeholder 属于文字。disabled 虽有对比度豁免，仍应可辨认，不能由透明度让禁用说明消失。焦点不能仅靠颜色变深或被 sticky/overflow 完全遮挡。
- 键盘操作保留原 Tab 顺序、组合键、焦点圈与回焦；不能正数 tabIndex 强排顺序。语义元素、可访问名称、label 关联、aria 状态、live region 保持正确；迁移不得产生重复名称或双重播报。
- 一般目标区域至少 **24×24 CSS px**，触屏目标 **44×44px**；对内联文本链接等适用例外按实际语义评估，不能机械把正文链接撑成按钮。受原布局约束而达不到时保留行为并登记，不能用覆盖邻居的透明层伪造命中区。
- 保留语言、方向、翻译 key 与格式化函数；已有 RTL 要实测。日期、货币、数字、时区和中英文标点不因字体统一改写。
- 浏览器/辅助技术自动检查只能辅助定位；未做完整审计不能宣称产品达到 WCAG 认证或全面合规。原有问题与本次回归分别记录，避免借换肤扩大为交互重构。

## 例外记录

记录在现有设计文档/迁移台账/会话报告中即可，不强制新增仓库文档或服务。每条例外至少有：

| 字段 | 内容 |
| --- | --- |
| 位置 | 路由、组件、必要的文件定位 |
| 目标与现状 | 例如 v3 标准行最小 44px；当前虚拟表格固定测量 32px |
| 原因与证据 | 具体受保护的行为/几何契约或明确用户要求；不得只写“兼容性” |
| 范围 | 哪个局部保持原值；字体/颜色等可独立部分仍迁移 |
| 验证和状态 | 已等价验证 / 受阻；用哪个流程确认，还有什么没检查 |

无法获取官方源码、字体、运行服务或测试环境时，继续独立可完成的工作，把相应项标为受阻。不能把“已映射 tokens”“没有 type error”报告成“全部 UI 与交互已验收”。

## 收尾与可回滚性

审查本次 diff 对行为源码、样式作用域、依赖和配置的影响。新增业务逻辑、隐藏内容、修改 API/状态/路由及未授权整页重建均须撤回本次对应改动。只回退本次适配，不破坏用户原有修改；不使用硬重置或删除整个工作树来撤销局部错误。

用户要求快照/提交时，先按现有授权建立本地回滚点并记录 commit；否则保留可审查 diff 即可，不自动提交/推送。字体、Lucide 图标及官方组件源码的许可和来源记录与实际发布物一同保留。

最终交付报告包含：主题版本与用户覆盖、实际覆盖页面/组件、官方替换与兼容保留、例外及未验证项、命令结果与入口截图位置。只报告实际完成的内容，不重复跑无关测试或把本轮技能更新说成项目已经应用。
