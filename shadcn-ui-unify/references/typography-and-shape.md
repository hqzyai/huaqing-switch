# 固定字体、排版与形状

应用 v3 的字体/形状时必读；本部分沿用 v2 的字体和形状选择。本规范是技能定义的跨项目设计基线，不是 shadcn 官方强制字体或默认 preset。数值的机器可读来源为 [neutral-theme.json](../assets/neutral-theme.json)；下表是其语义解释。

## 字体选择与交付

- 应用 UI：英文、数字使用 **Geist**；中文使用 **Noto Sans SC**。CSS 家族固定为 `"Geist", "Noto Sans SC", sans-serif`。
- 应用内代码、命令和日志：**Geist Mono**，中文回退到 Noto Sans SC。保留终端/编辑器用户自行配置的内容字体；不要改变编辑器测量和光标模型。
- 不再以 system-ui、微软雅黑、苹方、Arial 或每个项目现有 UI 字体作为默认设计字体。末尾 generic family 只负责字体加载失败时保证可读，不算验收通过。
- 默认自托管字体，沿用项目的字体构建和资产管线；核对官方发布物或所选字体包后固定版本，记录来源、文件与哈希。同批项目使用相同发布物，不各自解析 latest。不依赖运行时 Google Fonts 请求。
- 使用真实的 400、500、600 字重或覆盖该范围的可变字体；设置 `font-synthesis: none`，不把浏览器伪粗体当作 500/600。默认不使用 300、700、800、900 装饰 UI。
- Noto 中文字体应采用包含完整目标字符覆盖的分片/子集及正确的 `unicode-range`；不得只抽取当前页面文案，导致动态内容缺字。不预加载全部中文分片。缺少可获取字体时先完成其他迁移，明确标记字体受阻，不把 fallback 宣称为最终字体。
- 使用 `font-display: swap`，验证字体加载前后的换行、菜单宽度和长文本；不要通过禁用缩放、裁切文字或隐藏溢出来掩盖问题。

2026-10-12 已核对 [Geist / Geist Mono OFL](https://github.com/vercel/geist-font/blob/main/OFL.txt) 和 [Noto Sans 许可](https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE)，均为 SIL Open Font License 1.1。允许商用、嵌入和随软件分发；保留所分发字体随附的版权和许可证，字体不能单独售卖。OFL 不要求宿主应用开源。修改/重新发布字体时还需遵守完整许可证及保留名称条款；每次获取具体发布物时再核对其随附许可。

## 字号、行高与字重

以下 px 为根字号 16px 时的参考。实现用 JSON 中的 rem，不修改用户浏览器根字号，不禁止页面缩放。

| 角色 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 页面标题、统计主数字 | 28 / 36 | 600 |
| 区域标题 | 20 / 28 | 600 |
| 卡片、弹窗标题 | 16 / 24 | 600 |
| 普通 UI 正文、表格内容 | 14 / 22 | 400 |
| 长篇阅读正文 | 16 / 26 | 400 |
| 字段标签、按钮、菜单、导航 | 14 / 20 | 500 |
| 输入值、placeholder | 14 / 20 | 400 |
| 触屏输入值、placeholder | 16 / 24 | 400 |
| 辅助说明、时间、次要元数据 | 12 / 18 | 400 |
| Badge、Chip 文字 | 12 / 18 | 500 |
| 应用代码、命令、日志 | 13 / 20 | 400 |

触屏输入角色用于避免部分手机浏览器对小字号输入框聚焦时自动放大，复用已有移动端/触屏样式条件；不为此改动 JS 断点、布局切换或交互。正文强调与已选菜单使用 500；标题使用 600，不任意叠加加粗。统计数字可使用 tabular-nums，普通正文不强制等宽数字。默认 letter-spacing 为 normal，不给中文标题加负字距。

字号按语义角色统一，而不是把所有文字设成同一个大小。迁移已有内联样式、Tailwind utility、CSS Modules 和继承链中的覆盖值；禁止继续混用 13/15/17 等随意 UI 字号，除非登记了具体内容/测量兼容例外。保留语义标题标签，不因视觉字号重排 h1/h2 或替换标签。

## 圆角与方形的用途

| 组件 | 圆角与形状 |
| --- | --- |
| 普通按钮、图标按钮、输入框、文本域、选择器 | 6px 圆角矩形 |
| 卡片、弹窗、抽屉的外露角 | 12px 圆角矩形 |
| 下拉菜单、Popover、Toast、Alert、已有表格外框、Tabs 外容器 | 8px 圆角矩形 |
| Tooltip | 6px 圆角矩形 |
| Badge、筛选标签、上下文 Chip、Checkbox | 4px 小圆角 |
| Progress 轨道、Skeleton | 分别为 4px、8px；保持原尺寸与行为 |
| 头像、状态圆点、Radio、Switch 滑块 | 50%，保持原有正方形宽高和命中区域 |
| Switch 轨道 | 胶囊形，9999px |
| 表格内部单元格、分段组合控件的相接内角 | 0，外侧仍沿用所属控件圆角 |

默认不把主按钮、搜索框、筛选标签和卡片画成胶囊，不随意混用 16/20/24px 大圆角。卡片外框不等于其内部图片必须裁切；不要为了圆角新增 overflow:hidden，使浮层、焦点环或拖拽内容被截断。原生系统控件保持其原生行为，无法可靠控制的内部形状列为兼容保留，不替换为另一种交互。

边框统一 1px，颜色使用既有语义 border/input tokens。不通过改变边框厚度表示选中而挤动内容；焦点使用不占布局的 outline/box-shadow。尺寸和密度按 [间距与状态](layout-and-states.md) 的目标及例外规则执行，保留结构布局、命中行为和已有响应式切换。

## 验收及例外

检查代表性中文、英文、数字、长标签及真实字重对应字体文件，确认网络资源加载成功；`document.fonts.check()` 或 computed font-family 字符串不能单独证明没有发生字形回退。使用浏览器实际渲染字体信息，或结合已加载 FontFace、字符覆盖及画面检查验证。

对每类角色抽查 computed font-size、line-height、font-weight 和 border-radius，并搜索剩余硬编码覆盖；还须验证 200% 缩放、窄屏、表单焦点、列表滚动与弹层。字号改变影响现有虚拟化测量时，用既有测量机制复测；无法保持交互的局部控件暂留原几何并记录原因、原值、目标值和验证缺口。不得以“保留原样”为理由大面积跳过排版统一，也不得声称未达标部分已统一。
